# Bedrock Skin Downloader

Static Minecraft Bedrock gamertag skin lookup website.

Files:
- index.html
- style.css
- script.js

Upload all three website files to GitHub Pages.

The frontend uses:
https://vrc.lol/minecraft-api?username=GAMERTAG&type=bedrock
and:
https://vrc.lol/skin?username=GAMERTAG&type=bedrock

Third-party API availability determines whether a particular Bedrock skin can be retrieved.
