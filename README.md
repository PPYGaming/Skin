# Tamilcrafters Anime Search

A premium, API-free anime search landing page for GitHub Pages.

## Features

- Anime / character keyword search
- YouTube search links
- Instagram search links
- Facebook search links
- Premium glassmorphism UI
- Bubble / oval buttons
- Dark and light theme
- Mobile responsive
- No API key
- No backend required

## GitHub Pages

1. Upload `index.html`, `style.css`, and `script.js` to a GitHub repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Select your main branch and `/ (root)`.
5. Save and open the generated GitHub Pages URL.

## Important

This version does not scrape platform results. Search buttons open the official platform search pages. Therefore no API key is required.
